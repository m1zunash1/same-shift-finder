# 共通シフト検索

[共通シフト検索を開く](https://m1zunash1.github.io/same-shift-finder/)

同じ長さの2文字列に、位置ごとに同じシフトを適用します。両方が元の入力から変わり、選んだ辞書に載る組を表示します。

- 日本語どうし、英語どうし、日英の組に対応します。清音は五十音順、英語・ローマ字はABC順です。濁音（が〜ど）、ば行、ぱ行はそれぞれ独立した列を使います。
- 入力ごとに日本語か英字（英語・ローマ字）かを自動判定します。カタカナはひらがなに、英字は小文字にそろえます。`ぁぃぅぇぉゃゅょゎ` は入力側だけ大書きにそろえます。辞書側の小書きかなはそのまま扱います。
- 位置ごとのシフトに、−23〜＋23の範囲で共通の最小値と最大値を指定できます。ループを許容すると各文字列の先頭と末尾をまたげます。同じ出力の組に至るシフトは、位置ごとに絶対値が最小の値を表示します。同値の場合は負を優先します。
- 仔豚辞書、一般語辞書、イラスト辞書、英語辞書、ローマ字辞書を文字列ごとに複数選択できます。両方が英字の場合でも、一方をローマ字辞書、もう一方を英語辞書に指定できます。結果には各語が見つかった辞書と共通シフトを表示します。行を開くと1文字ずつの変換を確認できます。
- 文字列と辞書設定をまとめて左右入れ替えできます。シフト範囲には ±5・±10・±23 のプリセットがあります。
- 結果は単語で絞り込めます。50件ずつ表示し、絞り込み中も検索結果の全件をTSVで保存できます。

| 文字列1 | 文字列2 | 共通シフト | 結果 |
| --- | --- | --- | --- |
| ひつし | なすひ | +4, +23, +4 | まるた / のやま |
| ひつし | dog | 0, −6, −2 | ひしこ / die |

## 起動

このディレクトリで `python3 -m http.server 8000` を実行し、ブラウザで `http://localhost:8000/` を開きます。

辞書は `dict-data.js` に同梱しています。元の `nazo/dictionaries` から更新する場合は、ここで `node build-dict-data.mjs` を実行します。

## GitHub Pages

このディレクトリの中身を公開用リポジトリのルートに置きます。GitHubの **Settings → Pages** で **Deploy from a branch** を選び、公開するブランチと **/(root)** を指定します。ビルドは不要です。 [GitHubの手順](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)
